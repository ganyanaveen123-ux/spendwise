# SpendWise – Student Expense Tracker

## About
SpendWise is a student expense tracker that helps students record and manage their income and daily expenses.

## Features
- Dashboard showing total balance, income and expenses
- Add and delete transactions
- Categorise income and expenses
- Search transactions
- Filter by transaction type
- Monthly income and expense summary
- Category-wise expense breakdown
- Data persistence using Local Storage

## Technologies Used
- Next.js
- React
- JavaScript
- CSS
- React Context API
- Browser Local Storage

## Getting Started

Install dependencies:

npm install

Run the development server:

npm run dev

Open http://localhost:3000 in your browser.

## Project Purpose
The purpose of SpendWise is to help students monitor their spending habits and manage their personal finances more effectively.
