# SpendWise – Student Expense Tracker

## About
SpendWise is a student-focused expense tracker designed to help students record their income, monitor daily expenses, and manage their personal finances.

## Features
- Dashboard with total balance, income, expenses and transaction summaries
- Add income and expense transactions
- Categorise transactions
- Search and filter transactions
- Delete transactions
- Monthly income and expense overview
- Monthly budget tracking
- Category-wise expense reports
- Data persistence using browser Local Storage

## Technologies Used
- Next.js
- React
- JavaScript
- CSS
- React Context API
- Browser Local Storage

## Project Structure
- `app/page.js` – Dashboard
- `app/transactions/` – Transaction management
- `app/add-transaction/` – Add new transactions
- `app/reports/` – Expense reports
- `app/components/` – Reusable components
- `app/context/` – Expense management context

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Project Purpose
SpendWise aims to encourage better financial awareness among students by providing a simple way to track spending, monitor income and manage monthly budgets.
